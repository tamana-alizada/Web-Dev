# Web Development Labs

This repository contains my practice work and lab assignments for the **Web Development** subject at my university.

During this course, we studied the main tools and technologies used in modern web development, including **HTML**, **CSS**, **JavaScript**, **Angular**, and **Django**. Each folder in this repository contains different lab tasks and exercises that were assigned during the semester.

## 📚 What I Learned

Through these labs, I practiced:

* Building web pages with **HTML**
* Styling pages using **CSS**
* Adding interactivity with **JavaScript**
* Creating frontend applications with **Angular**
* Building backend features with **Django**
* Working with project structure and file organization
* Connecting frontend and backend parts of a web application

You can open each lab folder separately and check the source code inside.

For Angular or Django projects, follow the setup instructions inside the specific lab folder if available.
